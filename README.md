# Excel Automation

Скрипты для автоматизации работы с Excel через Python и pandas.

## Что решает

- Объединение нескольких Excel-файлов в один отчёт.
- Расчёт сводок по категориям: сумма, количество, средняя цена.
- Автоматическое формирование топ-N по заданному критерию.
- Сохранение результата в один файл с несколькими листами.

## Что внутри

- `make_test_data.py` — генерирует тестовые файлы с продажами за 3 месяца.
- `merge_sales.py` — объединяет файлы, считает сводку по товарам, сохраняет отчёт с топ-10.
- `requirements.txt` — зависимости проекта.

## Установка

```
pip install -r requirements.txt
```

## Запуск

```
python make_test_data.py
```
```
python merge_sales.py
```


## Результат

Файл `Итог_Q1.xlsx` с тремя листами:

1. **Все продажи** — объединённые данные из всех файлов.
2. **Сводка по товарам** — сумма, количество и средняя цена по каждому товару.
3. **Топ-10** — 10 самых продаваемых товаров по сумме.

## Используемые технологии

- Python 3.11+
- pandas
- openpyxl
