# Excel Automation

Набор скриптов для автоматизации работы с Excel через Python и pandas.

## Что решает

- Объединение нескольких Excel-файлов в один отчёт.
- Расчёт сводок по категориям: сумма, количество, средняя цена.
- Очистка баз клиентов: дубли, разные форматы телефонов, пробелы, опечатки.
- Сравнение двух версий прайс-листа: рост, падение цен, новые и удалённые позиции.

## Что внутри

- `make_test_data.py` / `merge_sales.py` — объединение файлов продаж и построение сводного отчёта с топ-N.
- `make_dirty_clients.py` / `clean_clients.py` — очистка и нормализация базы клиентов.
- `make_price_lists.py` / `compare_prices.py` — сравнение двух прайс-листов и поиск расхождений.
- `requirements.txt` — зависимости проекта.


## Установка

```
pip install -r requirements.txt
```

## Запуск

```
python make_test_data.py
```
```
python merge_sales.py
```


## Результат

Файл `Итог_Q1.xlsx` с тремя листами:

1. **Все продажи** — объединённые данные из всех файлов.
2. **Сводка по товарам** — сумма, количество и средняя цена по каждому товару.
3. **Топ-10** — 10 самых продаваемых товаров по сумме.

## Используемые технологии
